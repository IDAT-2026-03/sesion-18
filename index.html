¿Por qué todo el mundo ama Flexbox?

Por defecto en HTML, las cajas se apilan una debajo de otra como ladrillos hacia el piso. Flexbox es la herramienta mágica de CSS que las pone en fila con una sola línea de código y te permite moverlas como si fueran imanes.

PASO 1

La Regla de Oro: El Padre y los Hijos

display: flex

El error más común cuando empezamos es ponerle flex a la caja equivocada. Recuerda siempre esta analogía:

📦 El Padre es la Caja de Cartón:

Al contenedor exterior le dices display: flex;. Él es el jefe que da las órdenes de cómo acomodarse.

🧸 Los Hijos son los Juguetes:

Son las cajas de adentro (hijos directos). Mágicamente dejan de estar apilados hacia abajo y se ponen uno al lado del otro en una fila.

💡 flex-direction: Por defecto es fila (row). Pero si quieres que vuelvan a ser columna hacia abajo, solo pones flex-direction: column;.
Código Fácil
<!-- HTML -->
<div class="padre">
<div>Hijo 1</div>
<div>Hijo 2</div>
<div>Hijo 3</div>
</div>
/* CSS: Solo se lo pides al padre */
.padre {
display: flex; /* ¡Pum! Se ponen en fila */
}
📌 No lo olvides: Nunca le pongas display: flex a los hijos. Se lo pones al contenedor padre que los envuelve.
Paso 1: Activar Flexbox en el Padre Contenedor vs Elementos
PASO 2

justify-content: Mover a lo ancho

Horizontal

Una vez que tus cajas están en fila, ¿dónde las quieres ubicar? justify-content tiene los 4 valores que usarás en el 99% de tus webs:

flex-start

Todo pegado a la izquierda (inicio).

center

Todo centrado en el medio de la fila.

flex-end

Todo pegado a la derecha (final).

space-between

Uno a cada extremo (¡El rey del menú!).

⭐
El truco de oro: Con space-between, el logo se queda pegado a la izquierda y el botón se va solito a la derecha sin usar márgenes ni cálculos raros.

PASO 4

flex-wrap: Saltar de línea automáticamente

Multilínea

¿Qué pasa si tienes 10 productos y la pantalla es pequeña (como un celular)?

Por defecto (nowrap): Flexbox intenta apretar todas las cajas a la fuerza en una sola fila aplastándolas o saliéndose de la pantalla.
Con flex-wrap: wrap; (La Solución): Las cajas que ya no quepan en la fila bajan solitas a la siguiente línea de forma limpia y ordenada.
👉 Es la propiedad que te permite hacer galerías de fotos y catálogos de productos que se adaptan a celulares.
Catálogo Adaptable
/* Catálogo de tarjetas */
.catalogo-productos {
display: flex;
flex-wrap: wrap; /* Salto de línea automático */
gap: 16px; /* Separación limpia */
}
💡 Memorízalo así: wrap significa "envolver" o "dar la vuelta". Si no cabe, baja al siguiente renglón.
Paso 4: Evitar que las cosas se aplasten flex-wrap: wrap
TRUCO EXTRA

flex: 1 (Llenar el espacio vacío)

Elasticidad Simple

A veces pones dos cajas al lado, pero te queda un espacio en blanco feo a la derecha. ¿Cómo haces que una caja se estire para llenar ese hueco?

El comodín mágico: flex: 1

Si a un hijo le pones flex: 1;, le estás diciendo: "Estírate todo lo que puedas para ocupar el espacio libre restante".

Si se lo pones a todos:

Si tienes 3 cajas y a las tres les pones flex: 1;, ¡las tres se repartirán el ancho de la pantalla exactamente en partes iguales (33.3% cada una)!

Uso en la vida real
/* Barra lateral fija + Contenido expandible */
.menu-lateral {
width: 250px; /* Tamaño fijo */
}
.contenido-principal {
flex: 1; /* ¡Se estira para llenar la pantalla! */
}
📌 Ya no necesitas calcular con calculadora: Olvídate de hacer width: calc(100% - 250px). flex: 1 lo hace solo por ti.
Uso de flex: 1 en elementos hijos Reparto de Espacio Inteligente
LABORATORIO PRÁCTICO

Taller: El Menú Web Perfecto en 3 Pasos

Vamos a aplicar lo aprendido hoy para construir el componente más usado de internet: una barra de navegación profesional.

Paso 1: En el <nav> ponemos display: flex para que el logo, los enlaces y el botón estén en una fila.
Paso 2: Ponemos justify-content: space-between para que el logo se vaya al extremo izquierdo y el botón al derecho.
Paso 3: Ponemos align-items: center para que todos queden perfectamente alineados a la misma altura.
Paso 4: En los enlaces usamos display: flex; gap: 16px; para separarlos sin márgenes.
